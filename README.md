# Blazor Server DataGrid - EditTemplate with TimePicker

## Overview

This sample demonstrates how to customize editing within a Syncfusion Blazor DataGrid by rendering a TimePicker control inside an EditTemplate. Instead of relying on the default editor generated by the grid, the implementation uses a dedicated TimePicker editor for time-based fields during record editing. When users save their changes, the selected time value is updated in the underlying data source. This approach is useful for applications that require accurate and consistent time entry while maintaining an intuitive editing experience.

## Key Features

- Demonstrates DataGrid editing through a custom EditTemplate implementation.
- Renders a Syncfusion TimePicker control within the grid EditForm.
- Replaces the default editor for a time-based field with a specialized TimePicker editor.
- Updates the bound data source when edited values are saved.
- Shows integration between Syncfusion DataGrid editing infrastructure and a TimePicker component.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository to a local machine.
2. Open the solution file: `GridEditTemplateWithTimePicker.sln`
3. Restore all NuGet packages.
4. Set the startup project to:   `GridEditTemplateWithTimePicker`
5. Build the solution.
6. Run the application using `Ctrl+F5`.
7. Open the local URL displayed by the application after startup.
8. Edit a grid record to view the TimePicker rendered inside the EditForm.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the project directory.

```bash
cd EJ2-DataGrid-BlazorServer-GridEdit-EditTemplate-TimePicker
dotnet restore
dotnet run
```

4. Open the local URL displayed in the terminal after the application starts.
5. Navigate to the sample page and edit a grid row to test the TimePicker editing behavior.

## Project Structure
